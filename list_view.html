🏠 トップページ

GitHub Pagesで公開しているWebサイトのトップページです。

Webサイトのトップページを開く ↗

➕ ページを追加するとき

新しいHTMLページを追加した場合は、このHTMLファイルの「Webページ」一覧にカードを1つ追加してください。

ページ数が増えても同じ形式で追記できるようにしています。

<a class="card" href="HTML_PAGE_URL" target="_blank" rel="noopener">
  ...
</a>

🔧 更新手順

  1. HTML・CSS・JavaScript等のファイルを修正
  2. GitHubリポジトリへアップロード・コミット
  3. GitHub Pagesへの反映を待つ
  4. このページから対象ページを開く
  5. 実際のWebページで変更内容を確認

📝 管理ルール

  • リンク先にはGitHub上のHTMLファイルではなく、GitHub Pagesの公開URLを登録する
  • ページを追加・削除した場合は、この一覧も更新する
  • ページのURLを変更した場合は、この一覧のURLも更新する
  • ページ数が増えても、原則としてこの一覧に追記して管理する
